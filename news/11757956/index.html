FBs 系列 FATEK旗舰型PLC

FBs 系列  旗舰型PLC SoC-永宏的核心技术
FBs-PLC系以永宏自行研发之系统单晶片(SoC)制作而成，由超过12万闸之晶片整合了中央处理器(CPU) 、记忆体、硬体逻辑处理器(HLS)、5个高速通讯埠、4组硬体高速计数器/高速计时器、4轴具直线补间、 动态追踪之NC定位脉波输出及高速中断与输入捕捉等高阶功能硬体电路于一颗BGA晶片中，使速度 更快，功能及可靠度更佳，为同级PLC中的功能*强、价格*低、*具竞争优势者。

*人性化，功能*强之应用指令集

FBs-PLC指令超过300种以上，并采用*人性化，可读性*高之多输入/多输 出指令格式，一个指令即可达成大部分它牌PLC数个指令才能做到的功能， 使程式大为精简，同时运算结果可直接由内部或外部输出取得。在程式可 读性方面，每个应用指令之输入或输出端均有功能助忆简码说明，运算元 栏位则直接标明其属性简称并可于其正下方直接显示其状态或内容值，可 免除它牌PLC无标示需死记之麻烦，程式可读性*高，效率*佳。在高阶应 用方面，如PLC网路LINK、PID控制、NC定位等，FBs-PLC则有专用之便利指 令与之对应，大幅降低使用障碍。

睥睨业界之强大通讯功能
FBs-PLC之SoC晶片内部之通讯埠，即使在5个通讯埠均以*高速度 (921.6Kbps)运作下仍然游刃有余。可选用ASCII码或速度快一倍之二进码 来通讯。除永宏标准通讯协定外，尚可选用Modbus ASCII/RTU/TCP 通讯协 定或自订通讯协定，同时FBs-PLC具有8种通讯板和10种通讯模组可供各种 不同应用之弹性选择，为同级PLC中，通讯埠*多，通讯速度*快，功能* 强者。此外，每个通讯埠皆具有传送(Tx)及接收(Rx)之LED指示灯，以方便使 用者监视通讯运作状况及除错。

NC控制+PLC一体

将NC定位控制整合在FBs-PLC之SoC晶片内，使PLC+NC控制合为一体，共 享资源并省却两系统之资料交换。NC定位控制采用定位专用指令语言， 可任选机械单位或电气单位撰写程式，执行时能动态改变控制参数。单 机*大4轴输出，*高频率200 KHz (MC)或920 KHz (MN)，并可作多轴直线 补间与动态追踪。若配合FBs-PLC内建之4组HHSC，尚可作更精密之闭回 路之高速定位控制。
内建920KHz高速计数器
FBs-PLC*多可有4组硬体高速计数器(HHSC)及4组软体高速计数器(SHSC) ，HHSC*高计数频率为200 KHz (MC)或920 KHz (MN)，并具**、遮没 等功能。计数模式共有U/D、U/D x 2、P/R、P/R x 2、A/B、A/B x 2、A/B x 3、 A/B x 4 等8种，功能超强、效益*高。例如每转200 pulse之Encoder若使 用A/B x 4模式，将可提升到等同每转800 pulse Encoder之控制效果。且 其系由硬体执行，故不占用CPU时间。4组软体高速计数器(SHSC)则有U/D 、P/R、A/B三种计数模式，总和计数频率为5 KHz。

高速计时器

FBs-PLC提供0.1mS时基高速计时器之PLC(*多有32bit四 组，16bit一组)。业界多数PLC所提供之计时器时基*快只达1mS，其在精度要求较高之场合，便无用武之地。FBs-PLC之0.1mS高速计时器，因其时基误差仅0.1mS，再配合其中断的功能，即可轻易地完成较精密之速度侦 测或作成频率计，在大部分之情况下均可以此极经济之方式，取代昂贵之 速度侦测设备。

永宏的强大通讯功能

FBs-PLC之5个通讯埠可同时连结各种智慧型周边，界面则有USB、RS232、RS485、乙太网路 (Ethernet)、CANopen®、GSM、ZigBee™ 等可供选择，除可选用永宏标准通讯协定或Modbus通讯协 定或透过FATEK Communication Server通讯伺服器来通讯外，尚可利用CLINK通讯便利指令，自行定 义通讯协定，主动或被动地与任何智慧型周边连线。
齐全之通讯驱动软体
FBs-PLC除世界知名图控软体如Wonderware Intouch、Citec、 Labview、LabLink…及人机****如Digital、Fuji、Cermate、Hitech …等均支援与永宏通讯之驱动软体而能直接与FBs-PLC连线外，永 宏尚提供Modbus 通讯协定及永宏DDE标准通讯伺服软体(FATEK Communication Server)，让使用者在Office应用软体中或自行撰写程 式时，能轻易地连结FBs-PLC与各厂牌图控或各种电脑系统。 另外许多世界知名OPC大厂如National Instrument及KONTRON等，均 有贩售永宏专用之OPC套装软体供使用者选购。
附属周边*齐全
FBs-PLC除主机多达两百多种机型可供选择外，扩充I/O及附属周边亦有近 百种机型可任意搭配。除涵盖基本之数位I/O、类比I/O及多种通讯界面外， 尚包括指拨开关多工输入模组、16/7段LED显示模组及J、K、R、S、E、T、B、 N等8种热电偶或Pt100、Pt1000两种RTD之温度量测模组，以及*新推出 的电子磅秤用之荷重元模组与位置量测用之电子尺模组以及可让FBs-PLC 更具人性化与亲和力之语音模组。此外FBs-PLC尚提供可多台连线之FBsDAP或FBs-PEP简易人机界面，除可当Timer/Counter设定器外，尚可由使 用者自行定义专用按键及讯息显示，当简易人机界面使用。同时FBs-DAP 或FBs-PEP亦可附加RFID感应模组，作诸如门禁、停车设备、电梯乘载管制 等应用。
简单易懂之编辑环境
精心安排之编辑、监视、 除错等操作手顺，让使用者在极短时间内即可精通整体操作，加上 WinProladder强大且齐全之编辑功能辅以按键、滑鼠并用及线上即时 之指令功能查询与操作指引，将使您的编辑、输入效率倍增。而直接于 阶梯图上显示之〝即时″接点状态、暂存器数据与多视窗监视、比较等 功能，让使用者在作监视控制或除错时倍觉轻松写意。
单机36点捕捉式输入
FBs-PLC之SoC晶片内含之输入点捕捉功能，能对外界输入波宽低于扫描时 间之脉波作捕捉储存，以供CPU读取，相较于一般PLC对此种输入无能为 力或只能用复杂之中断处理而占用大量CPU时间，FBs-PLC则可当作一般输 入处理而不需使用者费心、不但效率高且*简易方便。
单机16点高速中断输入
FBs-PLC主机多达16点之外界中断输入，可让使用者自行定义外界输 入之正缘或负缘动作时发出中断，或正、负缘均发出中断，来作高速、 紧急之处理，排除CPU因扫描时间引起之延迟与误差，可用来作高速 精准定位、机械位置归零、高速RPM量测等高速且重现性需求较高之 应用。
